# 录制与介绍参考

录制前打开网页和已验收百炼会话，避免拍到 API Key、环境变量值、账号个人资料。使用明确日期，录制当天选未来日期；查询结果和价格随时变化，以当次真实返回为准。

## 建议顺序（约3—5分钟，可自行调整）

1. 首页与定位：狗拿主意帮人淘汰选项，有依据只推一个，没依据就不硬推。
2. 网页选住宿：输入杭州、未来入住日期、两晚一间房、总预算1000元、最低4分。展示主推、估算口径、图片、其他候选和真实详情链接。
3. 网页查旅行或聊行程：输入“我想从上海去杭州玩两天，不想赶场，帮我查交通和茶文化、博物馆玩法，推荐下面带上链接”。展示真实查询与 Markdown。
4. 百炼实际运行：打开“狗拿主意 · 核心旅行示例”会话。展示用户问题、工具已执行的记录，点 Agent 消息打开右侧“结果”，让观众看到渲染后的回答。环境已初始化，可直接续聊。
5. 边界与重选：发送“排除刚才的酒店，日期和预算不变，必须有可核实的隔音依据才主推；证据不够就直说，但候选和链接仍列给我”。展示条件保留、排除项，以及“证据不够，无法拍板”。
6. 收尾：展示 GitHub README、源码和复现说明，说明网页与百炼是同一作品的两个使用入口。

## 可直接说的开场

我想出门玩的时候，最烦的其实不是没信息，是信息太多。十家酒店都说自己好，攻略越看越不知道选哪个。所以我做了一只狗，让它替我淘汰选项。它有把握就推一个，没把握就直说，查到的东西和链接都摆在下面，让我自己也能核对。
